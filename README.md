## How to install a skill in Claude

1. Download the skill folder (for example `skills/duet-getting-started`). The easiest way is **Code > Download ZIP** on this page, then unzip it.
2. In Claude, open **Settings** and find **Skills** (under Capabilities).
3. Upload the skill. You can upload the folder as a ZIP, or just the `SKILL.md` file.
4. Make sure the skill is turned on.
5. Start a new chat and say something like "Help me get started with Duet." Claude will pick up the skill and walk you through it.
